## Product Overview

在现有《AI智能体科普实践课》互动教学系统中，新增一个独立的「作品展示」栏目，作为一个完整的"作品集"页面，向学生展示两个由四大组件真实搭建出来的智能体作品——「班级小助手」与「出行小管家」，并把它们的**制作过程**与**背后原理**讲清楚，学生可以现场与两个作品对话体验。

## Core Features

- **新增独立导航栏目**：顶栏新增第 8 个标签「作品展示」，与现有 7 个实验室并列；封面导览区新增一张入口卡片，点击直达。
- **作品一 · 班级小助手**：围绕班级事务（课表、值日、班级通知、提醒等）的智能体；含作品简介、制作过程、原理拆解、可交互演示。
- **作品二 · 出行小管家**：围绕出行（天气、行程、换算、提醒等）的智能体；结构同上。
- **制作过程分步图解**：把每个作品的制作拆成一串可视化步骤（定目标 → 配感知器 → 写系统提示词 → 装工具 → 接记忆 → 联调测试），配示意图，逐步可读。
- **原理拆解**：每个作品对照"感知器 / 规划器 / 记忆器 / 执行器"四大组件逐项说明它是怎么搭起来的。
- **可交互实时演示**：每个作品配一个真实对话区与数条「试试这样问」示例场景芯片，学生现场提问即可体验（需配置 API Key；未配置时给出清晰提示并降级演示）。
- **收尾对比小结**：说明两个作品都用了同一套四组件，差别只在"记忆内容"与"工具配置"。

## 视觉与交互效果

- 沿用系统现有的苹果风极简卡片审美：白色卡片、语义色强调、圆角与柔和阴影；为「作品展示」引入一个区别于七个实验室的新语义色（青绿/蓝绿系），页头图标、学习地图、预测条自动同色。
- 每个作品以"步骤条/流程图"呈现制作过程，节点清晰、可点击查看；演示区为聊天气泡式对话，输入框 + 发送按钮 + 场景芯片。
- 滚动进场动画沿用全站统一机制；窄屏自适应，JS 失效或开启"减少动态效果"时元素保持默认可见，不白屏。

## Tech Stack Selection

- 纯静态站点，**沿用现有技术栈**：原生 HTML + CSS + JavaScript（无框架、无构建、无新增依赖）。
- 复用现有模块与引擎：`AgentLab.LabPerception.card/labHead`（卡片与页头）、`AgentLab.UI`（图标/转义/打字机/toast/sectionMap/foldBrief）、`AgentLab.Agent.run`（真实智能体管线）、`quiz-flow.js` / `adv-classroom.js` / `reveal.js`。
- 不改动构建方式：直接通过 `启动_后台.bat` 起本地静态服务预览。

## Implementation Approach

核心策略是**复用现有"栏目 = section + nav-tab + lab-*.js"机制**，把新页面做成第 8 个并列栏目，并让两个作品成为**真正可运行的两个智能体**，而不是静态文字。

1. **栏目骨架复用**：`index.html` 新增 `<section id="sec-works">` 与导航标签；新增 `js/lab-works.js`；在 `main.js` 注册渲染。页面内部复用 `labHead` / `card` / `sectionMap` / `foldBrief` 等公共构件，保证与另外七个实验室口径一致。
2. **两个作品如何成为"不同的真实智能体"（关键决策）**：现有 `AgentLab.Agent.run()` 的系统提示词写死为"智能体小管家"、工具来自全局开关。为新增**"作品档案（profile）"**能力：`run(userText, history, hooks, profile)` 增加可选第 4 参，`profile` 携带该作品的系统提示词与启用的工具子集；内部让 `buildSys()`/`buildMessages()` 使用 profile 的提示词，`collectMemory()` 按 profile 的工具子集过滤 `tools`（`schemasFor` 无需改动）。**不传 profile 时行为与现状完全一致**，从而不影响"智能体实验室"。

- 之所以选这条而不是"在页面里直接调大模型、不接工具"：只有走真实管线，学生才能看到四大组件（尤其是执行器调工具、记忆器取班级知识库）真实协作，正好呼应本页"讲原理"的目标；且改动面被隔离在一个可选参数上，风险可控。
- 为降低侵入性，把 profile 挂进 `memory` 对象（`memory.profile`），仅在 `buildSys`/`buildMessages` 内用 `sysPromptFor(memory)` 统一取值，缺省回落到 `AgentLab.buildSystemPrompt`。

3. **内容组织**：每个作品 =「简介卡 + 制作过程分步图解卡 + 原理拆解卡 + 交互演示卡」；页面末尾加一张对比小结卡。制作步骤数据放在 `config.js` 的 `AgentLab.WORKS` 中，页面只负责渲染，便于后续增删作品。
4. **性能**：新栏目 `display:none` 直到激活，卡片为纯静态 HTML 拼接（一次性 `innerHTML`），无额外轮询；对话仅在用户点击时发起一次真实请求，与现有智能体实验室一致。复杂度为每页一次 DOM 渲染 + 按需网络请求，无性能负担。

## Implementation Notes

- **必须同步硬编码的栏目清单**：`js/ui.js` 的 `showSection` 内 `sections` 数组、`js/lab-perception.js` 的 `numberCards()` 内栏目数组都要加入 `"works"`，否则"切换不生效 / 卡片无编号"。
- **语义色要成套补齐**：`css/style.css` 中 `.lab-icon[data-color]`、`.sec-map[data-color]`（含 `.lab-brief`）、`.predict-bar[data-color]`、`.flow`/`quiz` 系列等映射组要为新色补一条，否则地图与预测条配色会回落到默认色。建议新增 `--c-works / --c-works-deep / --works-tint / --works-line / --works-ink` 变量。
- **向后兼容优先**：`agent.js` 的 profile 为可选参数，缺省路径（`profile` 未传或为 `undefined`）必须逐字节等价于现状；不改动 `lab-playground.js`。
- **失败降级**：未配置 API Key 时沿用现有 toast 提示与 `runRules` 降级演示；请求失败时用与智能体实验室一致的"卡住三步走"提示，避免白屏或未处理异常。日志/提示不打印密钥等敏感信息。
- **风格一致性**：内容口径与全站统一（规划器=决策职责、思考模式=能力开关、长期记忆借 system 角色），面向五年级学生；视觉沿用现有卡片/圆角/字体/语义色系统，保持克制。

## Architecture Design

```mermaid
graph TD
  A[index.html: nav-tab + sec-works + 脚本引入] --> B[js/lab-works.js 渲染模块]
  C[js/main.js init 调用 LabWorks.render] --> B
  D[js/lab-cover.js 导览卡] -->|data-goto=works| B
  B --> E[labHead / card / sectionMap / foldBrief 复用]
  B --> F[AgentLab.WORKS 作品档案 config.js]
  F --> G[AgentLab.Agent.run(profile) 真实管线]
  G --> H[感知→规划→记忆→执行→生成]
  H --> I[DeepSeek / 工具 / 班级知识库]
```

- 组件关系：`lab-works.js` 只做**渲染与交互**；作品内容（提示词/工具子集/示例场景/制作步骤）集中在 `config.js`；真实执行复用 `agent.js` 管线。三者职责分离，符合单一职责与开闭原则（新增作品只改 `WORKS` 数据）。

## Key Code Structures

```js
/* config.js —— 作品档案（跨模块契约：lab-works.js 渲染用，agent.js 执行用） */
AgentLab.WORKS = {
  classAssistant: {
    id: "classAssistant",
    name: "班级小助手",
    desc: "帮同学记事、查课表、做提醒",
    systemPrompt: function (classInfo, manual) { /* 返回该作品专属系统提示词 */ },
    toolKeys: ["classInfo", "remind", "calc", "datetime", "translate", "search"],
    suggestions: [ "今天下午有什么课？", "提醒我明天带美术工具", "帮我算 25×4+10" ],
    steps: [ { title: "定目标", text: "..." }, { title: "配感知器", text: "..." } ]
  },
  travelAssistant: { /* 同结构：天气 / 换算 / 时间 / 搜索 / 计算 / 提醒 */ }
};

/* agent.js —— 可选 profile（缺省行为与现状完全一致） */
async function run(userText, history, hooks, profile) { /* ... */ }
function sysPromptFor(memory) {
  return (memory.profile && memory.profile.systemPrompt)
    ? memory.profile.systemPrompt(memory.classInfo, memory.manual)
    : AgentLab.buildSystemPrompt(memory.classInfo, memory.manual);
}
```

## 设计说明

本页为**在既有设计系统内新增的一个栏目**，不改变全站设计语言，遵循现有苹果官网式极简卡片风格：纯白卡片、语义色强调、大圆角、柔和阴影、充足留白。为「作品展示」引入一套全新的**青绿（Teal）语义色**，与七个实验室（橙/金/蓝/橙/绿/红/紫）区分开，页头图标、学习地图、预测条自动同色。

## 页面结构（自上而下分块）

1. **页头区**：语义色图标（作品集图标）+ 标题「作品展示」+ 副标题胶囊（"看两个用四组件搭出来的真实智能体 · 作品集"）。
2. **导览区**：本课学习地图（可点节点跳转到对应卡片并高亮）+ 学习目标（并排可折叠卡，默认折叠）。
3. **作品一「班级小助手」**：

- 简介卡：一句话定位 + 它能帮同学做什么。
- 制作过程卡：横向步骤条（定目标 → 配感知器 → 写系统提示词 → 装工具 → 接记忆 → 联调测试），每步配小图标与一句话说明，可逐步点亮。
- 原理拆解卡：四大组件（感知/规划/记忆/执行）逐项对照说明。
- 交互演示卡：左侧聊天气泡区 + 输入框/发送按钮 + 「试试这样问」场景芯片，右侧一句"它背后的原理"注解。

4. **作品二「出行小管家」**：与作品一同结构，配色沿用同一套语义色。
5. **收尾对比小结卡**：两个作品并排对比——同一套四组件，差别在"记忆内容"与"工具配置"。

## 交互与动效

- 步骤条节点 hover 微动效、点击展开细节；演示区打字机式输出回答；场景芯片点击即发送。
- 卡片级滚动进场动画沿用 `reveal.js`；窄屏（≤734px）步骤条与对比卡自动回落单列。
- 未配置 API Key 时演示区显示友好提示条（沿用现有 toast/提示风格），不阻塞页面浏览。
