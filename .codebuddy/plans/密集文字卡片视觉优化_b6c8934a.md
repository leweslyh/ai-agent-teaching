## 产品概述

对现有静态教学系统中的 4 张「文字多、排版差、文字小」的卡片进行视觉优化，参照「深度思考：当 AI 似乎无所不能，我们作为人类该如何面对？」模块已有的设计风格（两栏 + 图标小卡 + 大字号 + 低密度），把它们重构为统一、易读、苹果风一致的卡片，并同步改造卡内冗长的结论框。

## 核心功能

- **参考样板风格统一**：沿用「深度思考」模块的「两栏容器 + 图标小卡 + 加粗小标题 + 说明副文」信息层级，替换当前 11–12.5px 小字堆砌。
- **优先改造 4 张卡片**：

1. CodeBuddy 深度拆解（首页）：长列表、小字、依据框整段 `ul/li`。
2. 大模型工作原理（起源）：8 段架构解读 11px、超长结论框。
3. 四种记忆存储格式（记忆）：每卡 5 行、字号 12–12.5px、无图标无分栏。
4. 认知科学三种记忆（记忆）：人类/Agent 两段 11.5px 密排。

- **长结论框改造**：把上述页面中 100 字以上的整段结论框（gold-box 之类）拆成带图标的要点条，提升可读性；过短的保留。
- **视觉一致性**：正文放大到 13–14px，统一圆角、内边距、语义色点缀，保持桌面端与窄屏（900/560px）自适应。

## 技术栈

- 纯静态项目：原生 HTML + CSS + JavaScript（无框架、无构建工具）。
- 公共卡片渲染函数：`AgentLab.LabPerception.card(color, title, sub, body)`，定义于 js/lab-perception.js:517；各页面以 `var LP = AgentLab.LabPerception; LP.card(...)` 调用。
- 图标工具：`U.icon(name, size)`；数据以 `.map()` 驱动渲染（参考 js/lab-origin.js:797-839 的 `fsx-*` 样板）。
- 样式集中在 css/style.css，采用「苹果风统一层 §1–§12」分区（约 6350 行起），新规则追加为新分区，避免覆盖旧规则。

## 实现方案

采用「新增一套通用低密度图标卡样式 + 逐卡重构 JS 结构」的策略，复用既有 §10.1 `fsx-*` 样板的视觉参数（圆角 16px、内边距、渐变图标块、字号阶梯），并把它抽象为可配色复用的通用类：

1. **新增 §13 通用样式**（css/style.css 末尾，现约 7619 行后追加）：定义 `tx-*` 系列类，用 CSS 变量 `--tx-c / --tx-c-deep` 参数化语义色，避免为每个实验室重复写样式。包含：

- 两栏结构：`.tx-cols / .tx-col / .tx-title / .tx-list`
- 图标小卡：`.tx-chip / .tx-ico / .tx-txt b / .tx-txt i`
- 多列图标卡：`.tx-grid / .tx-card / .tx-card-head / .tx-kv`
- 结论要点条：`.tx-points / .tx-point`（替代长 gold-box 的整段文字）
- 正反向标签：`.tx-ok / .tx-no`（复用 `--mem-tint/--exe-tint` 等派生色）
- 响应式：`@media (max-width:900px)` 两栏降一栏、`@media (max-width:560px)` 收紧内边距（对齐 §9 封面断点习惯）

2. **逐卡重构**：仅替换各卡 `body` 的 HTML 结构与局部字号，保留交互与数据来源不变；4 张卡分别把密排列表改为 `tx-chip` 两栏/多列，把整段结论框改为 `tx-point` 要点条。字号统一提升：小卡标题 14px/700、说明 13px/400、要点 13.5px。
3. **长结论框收敛**：在 js/lab-origin.js、js/lab-home.js、js/lab-memory.js 中，将 ≥100 字符的整段 gold-box/结论框改造成 `.tx-points` 结构；短句保留原样。

### 关键取舍

- 新增 `tx-*` 而不直接复用 `fsx-*`：`fsx-*` 的图标底色硬编码为 origins 的紫/蓝两色，无法适配 per/plan/mem/exe/brain 的语义色；用变量参数化后可跨实验室复用，符合现有语义色体系（DRY）。
- 不引入新框架或组件库：项目为零依赖静态页，保持零构建、可直接双击运行。
- 追加新分区而非改写旧规则：旧类仍被其他未优化卡片引用，避免连带回归（控制影响面）。

### 性能与可靠性

- 纯 CSS/HTML 结构替换，无新增脚本运行时开销；`.map()` 渲染为静态字符串拼接，复杂度 O(n)，n 为卡片条目数（≤8）。
- 不新增网络请求、不修改持久化逻辑；CSS 新增约 120–150 行，对首屏体积影响可忽略。

## 设计风格

延续项目既有「苹果风极简」体系，参照「深度思考」模块的低密度图标卡语言，对 4 张密集卡片做减法：以大字号、图标分栏、留白替代小字堆砌，形成统一视觉记忆。

## 视觉语言

- **两栏图标小卡**：左栏圆角渐变图标块（30×30，9px 圆角），右侧「加粗小标题 + 灰色说明副文」，卡底浅灰 `--c-bg-alt`，圆角 12px，项间距 8px。
- **多列小卡**：`auto-fit` 网格（约 2–4 列），卡内以键值行（key 深灰 12.5px/700、value 13px）替代纯段落。
- **结论要点条**：长结论框改为纵向要点列表，每行「图标 + 加粗引导词 + 说明」，行高 1.65，替代整段 130–330 字文字。
- **正/反标签**：`✓` 用记忆绿淡染、`✗` 用执行红淡染，圆角胶囊，替代内联小字。
- **语义色克制**：仅图标块与标签使用实验室语义色（变量参数化），卡外框保持中性描边，符合既有「大卡片外框不带色」约束。

## 布局与交互

- 桌面端两栏/多列并排；≤900px 降为单栏；≤560px 收紧内边距与字号，保证投屏与手机均清晰。
- 保留原有悬停/点击交互（如 CodeBuddy 各分区、记忆卡内容），仅替换静态排版；微动效沿用 `--t-base` 与会话既有过渡曲线。

## 一致性

- 复用令牌：`--c-ink/--c-ink-2/--c-sub/--c-line/--c-card/--c-bg-alt/--shadow-1/--shadow-2/--r-pill`。
- 字体沿用系统栈（PingFang SC / SF Pro / Microsoft YaHei）。
