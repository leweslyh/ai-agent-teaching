## 产品概述

对已有的「AI智能体互动学习实验室」静态教学系统做一次**纯视觉层的全站重构**：参考苹果官网的简洁现代风格，统一 7 个实验室（起源 / 总装图 / 感知器 / 规划器 / 记忆器 / 执行器 / 智能体实验室）以及顶部导航、弹窗、页脚、提示气泡的设计语言，建立一套可复用的设计令牌与组件规范，消除当前并存的多套色板与排版数值。

## 核心功能

- **配色体系统一**：页面底色由米白改为苹果式中性色（纯白 / 浅灰分带），四大组件语义色（感知器蓝、规划器橙、记忆器绿、执行器红，大脑金、起源紫）保留但降级为强调色，仅用于图标、编号徽章、进度条、边框与小面积色块，不再大面积铺色。
- **排版体系统一**：统一字体栈、字号阶梯、行高阶梯、字重与字距；建立标题 / 副标题 / 正文 / 辅助文字四级文字规范，保证课堂大屏投屏可读性不下降。
- **组件样式统一**：统一卡片、按钮、输入框、提示框、实验室页头、编号徽章、meta 胶囊、时间轴、流程图的圆角、阴影、内边距与层级关系，营造苹果式的留白与层次。
- **交互反馈统一**：统一 hover 抬升、active 回弹、focus 焦点环、切换过渡曲线与时长；新增轻量滚动进场动画，并尊重系统「减少动态效果」设置。
- **弹窗与页脚统一**：API Key 引导弹窗、设置弹窗、Toast、页脚改用统一的玻璃拟态 / 中性卡片语言，清除内联硬编码颜色。
- **响应式统一**：收敛断点，修复起源实验室大模型流程图等窄屏易挤爆的区域。

## 约束

- 所有现有教学内容文字（标题、正文、提示、选项、按钮文案、卡片脚注出处、页脚署名）**一字不改**，只允许改动 `class`、标签结构与 CSS。
- 不拆分 CSS 文件、不重写 lab 模板、不抽离 JS 组件层。

## 技术栈选型

沿用项目现有技术栈，不引入任何构建工具或框架：

- 原生 HTML / CSS / JavaScript（全局命名空间 `window.AgentLab`，无模块化、无打包）
- 样式：单文件 `css/style.css`（6205 行），采用**文件末尾追加覆盖层**的方式演进
- 服务：`_start_bg.ps1` 后台静态服务（端口 8124）
- 验收：`[skill:playwright-cli]` 做浏览器截图与文本快照比对

## 实施方案

### 总体策略：令牌层 + 末尾覆盖层 + 定点内联迁移

项目 CSS 是「按需求追加」的堆积体（6205 行，38 处 `!important`，`body`/`.card`/`.btn` 各有 2 次定义）。**不删除、不重写任何既有规则**，全部新增内容追加在 `css/style.css` 末尾，利用「同特异性后者胜」的层叠规则生效。经勘查，既有重复定义（L1373 `body`、L1404 `.card`、L1490 `.btn`）均在文件中部，末尾追加可稳定覆盖。

1. **令牌层**：在文件末尾追加**第二个 `:root` 块**（不改动 L7–73 原令牌），重定义全部设计变量。原 `:root` 位于 L7，新 `:root` 位于文件末尾，同特异性后者胜，安全生效。注意 L6210 的 `@media (max-width:768px){:root{--topbar-h:108px}}` 会被末尾块覆盖，需在新块之后补一条移动端 `--topbar-h` 覆写。
2. **基础层**：重定义 `body` 字体栈与排版基线、页面容器节奏、链接样式。
3. **组件层**：导航 / 卡片 / 按钮 / 表单 / 提示框 / 页头 / 编号徽章 / meta 胶囊 / 弹窗 / Toast / 页脚。
4. **定点内联迁移**：`js/lab-origin.js` L534–572 大模型流程图（唯一「整段布局+配色内联」、且窄屏必炸的区域）改为 class；`js/lab-perception.js` L418 `labHead()` 的内联渐变改为 `data-color` 驱动。
5. **动效层**：新增 `js/reveal.js`（IntersectionObserver 进场），统一 transition 属性与缓动曲线。

### `!important` 与反压风险（实施前必须审计）

既有 38 处 `!important`（典型 L1601、L5642）会**无条件压过**后续的非 important 规则。执行第一步用 `[subagent:code-explorer]` 全量列出这 38 处的「选择器 + 属性」，凡与新规范冲突的属性（主要是 `background`、`color`、`border-radius`、`padding`、`display`），在覆盖层中**同样加 `!important`** 并写注释说明原因；不冲突的一律不加。

### 动效规范

- 统一 `transition-property` 为 `transform, box-shadow, background-color, border-color, color, opacity`，**去掉 `transition: all`**（既有 78 处，覆盖层对主干选择器覆写；余者不动）。
- hover：`translateY(-2px)` + `--shadow-3`；active：`translateY(0) scale(.985)`；focus-visible：`outline:2px solid var(--c-accent); outline-offset:3px`（替换现有金色 3px 环）。
- 滚动进场：新增 `js/reveal.js`。**安全降级设计**：只有当 JS 成功执行并给 `<html>` 加上 `js-reveal` 类后，`.js-reveal .reveal{opacity:0;transform:translateY(14px)}` 才生效；JS 失败或禁用时元素默认可见，绝不出现白屏。进场目标仅取 `.card` / `.lab-head` / `.lesson-divider`，用 `transition-delay` 做 60ms 阶梯。
- 全部新增动画纳入 `@media (prefers-reduced-motion: reduce)` 关闭。
- 既有 `@keyframes shake`（4 份重复）、`fadeIn*` 系列（5 份重复）**不去动**（删除会波及各 lab 绑定），只新增规范命名的新关键帧。

### 响应式

保留既有 38 处 `@media`（它们各自生效），在覆盖层末尾**新增**一组苹果式断点 `1068px / 734px / 480px`，只负责：① 新令牌的移动端覆写（含 `--topbar-h`、卡片内边距、标题字号）；② 修复 `llm-flow`、`.transformer-arch`（L5214 `grid-template-columns:1fr 60px 1fr`）等窄屏易炸区；③ 统一容器左右留白。

### 执行要点（防回归）

- **文字零改动自检**：改造前用 `[skill:playwright-cli]` 打开 `http://localhost:8124/index.html`，遍历 7 个 `data-sec` 依次点击，导出每次 `document.getElementById('sec-xxx').innerText` 存为快照；改造后再导出一次做逐字 diff。这是唯一可靠的验证手段（内容由 JS 动态生成，静态 diff 不可靠）。
- **改动前后对比**：同一脚本同时输出每个栏目首屏截图，用于确认视觉未塌陷。
- **改动范围控制**：JS 文件的 diff 必须只出现在 `class="..."` / `style="..."` 片段内；若 diff 落到中文字符串上，立即回滚该处。
- **性能**：覆盖层不使用 `transition: all`；`reveal.js` 用单个共享 `IntersectionObserver` 实例 + `unobserve` 后立即解绑，避免长列表持续回调；进场只对 `.card` / `.lab-head` / `.lesson-divider` 生效（单栏目通常 < 30 个节点）。
- **回滚**：每段覆盖层用独立注释块包裹（如 `/* ===== 苹果风统一层 §3 组件 ===== */`），出问题可整段摘除，不影响原样式。

## 设计风格

采用**苹果官网式极简现代风格（Apple HIG / Minimalism）**：大面积留白、中性底色、细描边替代重阴影、克制的强调色、大字号标题配紧字距、柔和的悬停抬升与渐进入场。整体观感干净、通透、有秩序，同时保留教学所需的组件色彩辨识度。

## 页面规划（统一模板，7 个栏目共用）

### 屏幕一：全局框架层（所有页面共有）

- **顶部导航**：毛玻璃吸顶栏（`rgba(255,255,255,.72)` + `backdrop-filter:saturate(180%) blur(20px)`），底部 1px 细分隔线。品牌区为圆形渐变图标 + 双行标题；右侧 7 个栏目切换胶囊，默认中性文字透明底，激活态为「语义色 12% 淡染底 + 语义深色文字 + 8px 语义色圆点」，hover 时淡灰底并轻微上浮。最右为设置图标按钮。
- **页脚**：浅灰 `#F5F5F7` 分带，两行小字，细上边框，文字密度与导航栏呼应。

### 屏幕二：实验室页头区块

- 大号标题（34px / 700 / 字距 -0.5px）+ 副标题（17px / 次级色），下方为 meta 胶囊组（课程编号、课时、目标）。整体置于 `#F5F5F7` 浅灰分带内，形成苹果式「分带呼吸感」，左侧配 64px 语义色渐变图标。

### 屏幕三：知识卡片内容流

- 单列纵向卡片流，卡片宽 100%、圆角 20px、纯白底、1px 淡描边 + 双层柔和阴影，卡片间距 24px。左上角为语义色淡染编号徽章，标题 24px，副标题次级色，脚注为虚线分隔的浅色出处行。卡片 hover 上浮 2px 并加深阴影。
