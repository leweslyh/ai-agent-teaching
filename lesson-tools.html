工具调用小课堂

先回顾三课：会看 → 看明白 → 会点单。今天补最后一环——手到底伸向哪里？

只看一件事：一个接口长什么样——地址 · 钥匙 · 参数 · 返回；第 ⑧ 关会真发一次请求，让你看见同一次调用在四个视角里各是什么样。

老师提示（上课前看一眼）
这一页是什么：第 08 课的大屏课堂版，十关对应教案第一学时与第二学时：回顾三课 → 本课地图 → 一个接口长什么样 → 四步法 → 搜索 vs 抓取 → 出行小助手需求清单 → 高德一把钥匙开很多门 → 请求↔响应（真实调用） → 排错实录 → 编写与运行。前九关在第一学时（40′），第十关是第二学时的编写与运行。
第 ⑧ 关是真的：模型一轮一轮来——先根据输入点单，拿到工具结果后可能继续点单（比如先 IP 定位拿城市、再查天气），直到能直接作答，最多 4 轮；每轮之间的工具由程序执行，四块里每一行都来自网络返回。所以上课前必须先在首页右上角「设置」里填好 DeepSeek Key，否则它只会显示"发出去的样子"，不会假造响应。外部工具全部是高德 Web 服务 API，所以还要在那一关输入Web 服务类型的高德 Key；没填时工具会如实返回"没有高德 Key"，不会偷换别的接口。高德 IP 定位只解析 IPv4，手机热点/校园网常是 IPv6 出口，这时程序会再用 myip.ipip.net 兜底（会把出口 IP 发给该站点，介意可在讲解时跳过这一步）。
大屏：右上角「A− / A+」调字号（85%～150%，会记住），「全屏」进投影模式；右下角「上一张 / 下一张」控节奏；键盘 ← → 也能翻。
建议节奏（第一学时 40′）：回顾 2′ · 地图 1′ · 接口长相 3′ · 四步法 3′ · 搜索抓取 6′ · 需求清单 3′ · 一把钥匙开很多门 8′ · 真实调用 8′ · 排错 6′；第二学时：编写运行 6′（其余时间给学生动手）。
四处可点：第 ⑤ 关切换「只提问题 / 给了网址」；第 ⑦ 关点「数一数：几把钥匙」；第 ⑧ 关先拨工具开关看左下请求体怎么变，再点左上「用户输入」卡里的「发送」（推荐顺序：关掉天气、只留路线看它只点一只 → 全关掉看它只能凭印象 → 再全打开连调两只）；第 ⑨ 关对照 Console / Network 那张表。四块展示区都是固定高度，内容长了拖右侧滑块往下看。
上课前务必准备：在高德开放平台申请 Web 服务 Key（每组一个，5～6 人共用）发到学生桌面；自己先填一遍 DeepSeek Key + 高德 Key，把第 ⑧ 关点通一次。
