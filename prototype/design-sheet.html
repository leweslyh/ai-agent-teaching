我的智能体设计单原型

前面八课你一直在“操作”别人的智能体。这一页换你自己当设计者：选场景 → 写目标 → 挑工具并写说明书 → 定记忆规则 → 亲手写岗位说明书 → 自评导出。填完可以直接把这份设计单送进实验室跑一次，看看别人（AI）按你的说明书能不能把活干对。

1我的智能体要帮谁、做什么？场景
先选一个真实场景（或者自己写一个）。场景越具体越好——“帮同学”太模糊，“帮我们班下午的值日生提醒打扫哪几个区”就清楚了。
2一句话说清它要干成什么规划器
这就是给智能体的“任务说明书”。四要素齐全，它才不容易跑偏：帮谁 · 做什么 · 做到什么程度 · 什么情况先说“不知道”。
四要素体检 （自己逐条检查，四个都打勾才算说清楚）
3它需要哪些“手脚”？（挑工具 + 写说明书）执行器
勾选需要的工具后，每个工具下面都要写一句“给 AI 看的说明书”：能干什么、要什么参数、什么时候用它。写得含糊，AI 就会选错工具、传错参数——这一步是整份设计单最容易被跳过、也最值钱的地方。
4它该记住什么、绝不该记什么？记忆器
记忆让智能体越用越顺手，但也会一直影响它后面的回答——所以“不该记什么”必须写下来。
提示：凡是“泄露出去会让同学不舒服”的，一律写进右边这一栏。
5亲手写它的“岗位说明书”（规则）上下文工程
这一栏就是你写给 AI 的岗位说明书——它会出现在每一次对话的最前面（也就是 system 指令）。三条规则分开写，比混成一段更难被忽略。

⑦ 把这份设计单送进实验室跑一次

        
用你写的岗位说明书 + 工具说明书，去问它一个真实问题。这一步是来真的：你写的说明书会作为接口的 tools 参数发给模型，模型自己决定调哪个工具、传什么参数，工具在本机真的执行，结果再回给模型——这就是 ReAct 循环。看它是按你的规则干活，还是像没看过说明书一样自说自话。
